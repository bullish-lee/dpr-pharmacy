# 실데이터 규칙

이 저장소는 공개 저장소입니다. **실제 약국 자료는 저장소·이슈·PR 어디에도 넣지 않습니다.** 테스트 데이터는 모두 합성 데이터입니다.

## 넣지 않는 자료

| 종류 | 예 |
|---|---|
| 실제 거래·재고 자료 | 사입·조제·재고 수량, 단가·금액, 거래일, 제조번호·유효기간·일련번호 |
| 도매 관련 | 실제 도매 이름과 거래량·보상 조건이 함께 있는 자료, 도매별 계약 내용 |
| 약국 식별정보 | 약국 이름·주소·요양기관기호, PC·네트워크·보안 프로그램 환경, 공동인증서 관련 정보 |
| 개인정보 | 환자 정보(조제현황은 '환자정보 삭제본'만 씁니다), 사용자 연락처 |
| 업무포털 '인가자' 자료 | 약가유연계약 실제 상한금액 등. **외부 반출 금지** |

복지부 고시, 심평원 공개 목록, 제품명 자체는 공개 자료입니다. 다만 **특정 약국의 거래와 연결되면** 넣지 않습니다.

## 지키는 방법

- 실제 데이터 파일은 `.gitignore`에 있습니다(`data/`, `*.db`, 루트 xlsx, `realdata/`).
- 실데이터 회귀 테스트는 저장소 밖 폴더(`DPR_REALDATA`)를 쓰고, 기대값도 그 폴더에 둡니다.
- 오류 보고는 경로·파일 이름·토큰을 가리고, 거래 자료를 넣지 않습니다. 이슈를 올리기 전에 내용을 한 번 더 확인해 주세요.
- 실수로 올렸다면 이슈·PR은 바로 지우고, 커밋은 기록에서 지운 뒤 소유자에게 알려 주세요.
- `make sensitive`로 '민감자료' 표시가 남은 곳이 없는지 확인합니다.
