급여약품 관리 (DPR) — Windows용

[처음 실행]
1. 이 zip을 원하는 폴더(예: C:\DPR)에 압축 해제합니다.
2. DPR.exe 를 실행합니다. 설치는 필요 없습니다.
   - Windows 10/11 에 기본으로 들어 있는 WebView2 를 사용합니다.
   - "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누르세요 (코드 서명 전이라 나오는 안내입니다).
3. 자료는 기본으로 %APPDATA%\DPR 폴더(C:\Users\<사용자>\AppData\Roaming\DPR)에 쌓입니다.
   - dpr.db   : 모든 자료 (사입·조제·재고·고시·수정 기록)
   - logs     : 기록(로그) — 오류 보고 때 씁니다
   - backups  : 하루 1번 자동 백업 (최근 30개)
   설정 → 데이터·백업에서 위치를 보고, 폴더를 열고, 옮길 수 있습니다.
   - 데이터 폴더 옮기기: 빈 폴더(예: D:\약국자료)를 고르면 자료를 옮기고 다시 시작합니다. 원래 폴더는 지우지 않습니다.
     다른 PC에서 가져온 자료 폴더를 고르면 그 자료로 바꿉니다.
   - 백업 폴더 바꾸기: USB·외장 디스크 등 다른 곳에 백업해 두면 PC가 고장 나도 되살릴 수 있습니다.
   DPR.exe 옆에 dpr-data 폴더를 만들어 두면 그 폴더에 저장합니다 (USB 휴대용).

[자동으로 받는 자료]
- 복지부 약가 고시: 하루 3번 + 켤 때 자동으로 확인합니다.
  지난 1년 고시(2025.10 ~ 2026.10, 14건)는 프로그램에 들어 있어 처음 켤 때 자동으로 들어갑니다.
- 표준코드(바코드 ↔ 보험코드): 하루 1번 새 판을 확인하고, 나온 날만 받습니다.
- 약제급여목록(전체): 공공데이터포털 무료 인증키를 한 번 넣으면 매달 자동으로 받습니다.
  '데이터 가져오기' (또는 설정 → 자동 확인) 에서 [인증키 넣기]를 누르면 받는 방법이 단계별로 나오고,
  필요한 페이지를 버튼으로 바로 열 수 있습니다. 키를 붙여 넣고 [확인하고 저장]을 누르면 바로 확인해 줍니다.
- 사입·조제·초기재고는 이팜에서 내려받아 '데이터 가져오기'에서 올립니다.

[약품 조회]
- 왼쪽 메뉴 '약품 조회'에서 제품코드·약품명·바코드(스캐너로 찍어도 됨)·주성분코드 중 아무거나 넣으면 서로 찾아 줍니다.
  규격·고시 단위·상한금액, 바코드별 포장 수량, 고시 가격 변화, 이 약국의 재고·사입·조제, 같은 성분 다른 제품을 함께 봅니다.

[옮긴 폴더가 안 열릴 때]
- 데이터 폴더를 USB·외장 디스크로 옮긴 뒤 그 드라이브가 빠져 있으면, 빈 자료로 열지 않고 안내 창을 띄웁니다.
  드라이브를 연결하고 다시 켜세요.
- 기본 위치로 돌아가려면 안내 창에 나온 파일(%APPDATA%\DPR-data-location.txt)을 지운 뒤 다시 켜세요.
  기본 위치(%APPDATA%\DPR)에는 옮기기 전의 옛 자료가 있으니, 옮긴 폴더를 되찾을 수 없을 때만 지우고 가장 최근 백업으로 되살리세요.
- 데이터 폴더는 네트워크 폴더(NAS·공유 폴더)에 둘 수 없습니다 (자료가 손상될 수 있음). 백업 폴더로는 쓸 수 있습니다.

[업데이트]
- 프로그램을 켤 때 새 버전이 있으면 화면 위쪽에 알림이 뜹니다. [업데이트]를 누르면 받아서 다시 시작합니다.
- 데이터 폴더는 그대로 유지됩니다. 업데이트 전에 자동으로 백업합니다.
- 개발자 서명이 맞는 파일만 설치합니다 (다른 사람이 올린 파일·손상된 파일은 설치하지 않음).
- 업데이트 뒤 처음 켤 때까지는 이전 버전이 DPR.exe.old 로 남아 있습니다.
  새 버전이 켜지지 않으면 DPR.exe 를 지우고 DPR.exe.old 의 이름을 DPR.exe 로 바꾸면 되돌아갑니다.
  자료는 그대로 열립니다 (자료 구조는 항상 '추가'만 바꿉니다).
  (새 버전으로 한 번 더 정상적으로 켜면 DPR.exe.old 는 자동으로 지워집니다)
- 업데이트 도중 PC가 꺼져 DPR.exe 가 없고 DPR.exe.new 가 있으면, DPR.exe.new 의 이름을 DPR.exe 로 바꾸세요
  (또는 DPR.exe.old 를 DPR.exe 로 — 이전 버전).

[백업에서 되살리기]
- 백업은 백업 폴더(설정 → 데이터·백업 → [백업 폴더 열기])에 dpr-날짜-시각.db 로 하루 한 번 쌓입니다 (30개 보관).
- 되살리기: ① 프로그램을 닫습니다. ② 데이터 폴더의 dpr.db 를 다른 이름(예: dpr-고장.db)으로 바꾸고,
  dpr.db-wal · dpr.db-shm 이 있으면 지웁니다. ③ 되살릴 백업 파일을 데이터 폴더에 복사해 이름을 dpr.db 로 바꿉니다.
  ④ 프로그램을 켭니다. 백업한 뒤에 올린 자료(사입·조제 등)는 다시 올려야 합니다.

[프로그램 지우기]
1. 작업 스케줄러에 등록했다면 먼저 해제합니다: 설정 → '꺼져 있어도 확인' → [등록 해제].
   (프로그램 없이 지울 때는 Windows '작업 스케줄러' → 작업 스케줄러 라이브러리 → DPR 폴더를 지웁니다.)
2. 프로그램을 닫고 DPR.exe 가 있는 폴더(예: C:\DPR)를 지웁니다. 설치 프로그램이 없으므로 이것으로 프로그램은 지워집니다.
3. 자료까지 지우려면 아래도 지웁니다. 지우면 되살릴 수 없으니 필요하면 백업을 먼저 다른 곳에 옮겨 두세요.
   - 데이터 폴더: 기본 %APPDATA%\DPR (옮겼다면 설정 → 데이터·백업에 나온 폴더)
   - 위치 기록 파일: %APPDATA%\DPR-data-location.txt (데이터 폴더를 옮긴 경우에만 있음)
   - 백업 폴더를 따로 정했다면 그 폴더의 dpr-날짜-시각.db 파일
   - 휴대용으로 썼다면 DPR.exe 옆 dpr-data 폴더

[문제가 생기면]
- 설정 → 오류 보고 를 누르면 기록(로그)을 모아 개발자에게 보냅니다. 약국 거래 자료는 보내지 않습니다.
